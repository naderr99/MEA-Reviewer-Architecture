# MEA-Reviewer-Architecture
Zero-server HTML/JS clinical workspace built to replace error-prone Excel sheets when auditing AI vs. human ICD-10-CM/PCS codes. Synced via Python sharding over Enterprise OneDrive (inside the HIPAA boundary), it pairs an aligned code matrix with an embedded EHR viewer, ICD-10 lookup, and JSON/CSV export—eliminating 100% of concurrency overwrites.
