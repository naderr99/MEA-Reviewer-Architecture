Clinical Coding AI vs. Human Adjudication Workspace

System Architecture & Clinical Informatics Engineering Case Study

Nader Abdelrahman, BPharm, BCPS AI Solutions Engineer & Senior Clinical Informatician

1. Broken Clinical Workflow

Manual error analysis of AI vs. human ICD-10-CM/PCS codes over shared Excel files caused concurrent user overwrites, file lag, and slow window-switching to read EHR charts.

2. Architectural Solution

Engineered a zero-server HTML/JS adjudication workspace paired with a Python partitioning script over enterprise OneDrive—staying 100% inside the existing HIPAA boundary.

3. Measured Outcome

Eliminated 100% of concurrency overwrite collisions, unified EHR chart review + ICD-10 lookup into one screen, and cut per-patient adjudication time by ~50%.

System Architecture Blueprint
Layer 1 : Multi-Source Clinical Data Ingestion (RCM / EHR)

Patient EHR Documentation

  • Discharge Summaries & ICU Notes
  • Operative, Cath Lab & Radiology Reports

AI Medical Coding Output

  • AI-generated ICD-10-CM Diagnoses
  • AI-generated ICD-10-PCS Procedures

Human Production Coders

  • Baseline human-abstracted code sets
  • Historical ground-truth benchmark
Raw Dataset Ingestion
Layer 2 : Python Automation, Code Alignment & Sharding Engine

1. Algorithmic Code-Pair Alignment

  • Pairs matching or sibling AI & Human ICD-10 codes into unified comparison rows
  • Flags unaligned discrepancies (AI-Only vs. Human-Only misses)

2. Deterministic Reviewer Queue Sharding

  • Partitions dataset by reviewer_username to eliminate Excel concurrency locks
  • Injects patient EHR text directly into isolated user state payloads
Automated Background Sync (Zero External Web Servers)
Layer 3 : Enterprise OneDrive HIPAA Boundary (Serverless Storage Layer)

Isolated Reviewer Shards

  • queue_{username}.json
  • Zero cross-user overwrite risk

Embedded ICD-10 Index

  • icd10_cm_pcs_dict.json
  • Local billable & sibling hierarchy

Single-File App Bundle

  • adjudication_viewer.html
  • Runs natively in local browser
Local File Mount via Username Authentication (Zero Network Latency)
Layer 4 : Client-Side HTML/JS Adjudication Workspace (Reviewer DOM)
LEFT PANE : ALIGNED ADJUDICATION MATRIX
  • Aligned Code Verdicts: 1-click Both Correct, Both Wrong, AI Only, or Human Only
  • Conditional Error Taxonomy Drawer:
    • Code Should Not Exist (False Positive)
    • Overspecified vs. Underspecified
    • Weak Documentation vs. Wrong Sibling
  • Correction Input: Free-text replacement ICD-10 code + clinical rationale
RIGHT PANE : EMBEDDED EHR CHART VIEWER
  • Draggable Split-Screen Resizer: Expand, collapse, or resize patient notes beside codes
  • Multi-Tab Clinical Notes: Instant switching between Discharge, ICU, Operative, and Lab tabs
  • Zero Context Switching: Eliminates toggling between Excel and external EMR windows
UTILITY : ICD-10-CM/PCS LOOKUP
  • Slide-Over Search Drawer: Instant code & description query without leaving patient view
  • Sibling Inspection: Verifies laterality, episode of care, and specificity rules
1-Click Client-Side Export (.json / .csv)
Layer 5 : Adjudication Results Export & Quantitative Error Analysis

Structured Reviewer Judgements (CSV / JSON)

  • Exports adjudicated patient rows with side-by-side AI vs. Human verdicts
  • Includes assigned error categories and corrected replacement ICD-10 codes

Downstream Error Analysis & Reporting

  • Aggregates clean reviewer exports without spreadsheet merge conflicts
  • Enables direct statistical evaluation of AI vs. Human coding accuracy and error distribution
